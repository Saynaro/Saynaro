## 🛠 Projet principal

### 💻 [SaaS Pro — Plateforme SaaS Enterprise-Ready](https://saaspro.online)

Une plateforme SaaS complète de gestion de projet collaborative avec synchronisation en temps réel, conçue avec une approche *"Security & DevOps by Design"*.

[![Demo Live](https://img.shields.io/badge/Demo%20En%20Ligne-saaspro.online-blue?style=for-the-badge&logo=google-chrome&logoColor=white)](https://saaspro.online)
[![GitHub Repo](https://img.shields.io/badge/Code%20Source-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/Saynaro/saas-task-manager)

**Points clés de l'architecture :**
- ⚡ **Temps réel** : Messagerie instantanée et notifications globales d'activité gérées via **Socket.IO**.
- 🚦 **Sécurité & Performance** : Limitation de débit (Rate Limiting) gérée distribuée sur **Redis** pour sécuriser les routes d'authentification.
- 🔐 **Authentification Robuste** : Système double-token (JWT Access + Refresh en cookie HttpOnly sécurisé anti-XSS) et intégration de Google OAuth2.
- 📦 **Infrastructure & DevOps** : Architecture entièrement conteneurisée avec **Docker & Docker Compose**.
- 🌐 **Déploiement Hybride** : Application déployée en production avec le Frontend sur **Vercel** et le Backend/Bases de données sur un serveur VPS **Hetzner**.

**Stack :**  
`React 19` · `Vite 8` · `TailwindCSS 4` · `Node.js` · `Express` · `Socket.IO` · `Redis` · `PostgreSQL` · `Prisma ORM` · `Docker` · `Hetzner` · `Vercel`
